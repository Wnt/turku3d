# Tree model provenance

Four unmodified source GLBs from Kenney **Nature Kit 1.0** (2020), downloaded
2026-10-25 from https://kenney.nl/assets/nature-kit (CC0-1.0).
The original `License.txt` accompanies every model in this directory.

| File | Visual use |
| --- | --- |
| tree_default_fall.glb | Smaller deciduous trees |
| tree_detailed_fall.glb | Large deciduous trees |
| tree_oak_fall.glb | Broad oak/elm crowns |
| tree_pineDefaultA.glb | Conifers |

Source archive: https://kenney.nl/media/pages/assets/nature-kit/37ac38a37b-1677698939/kenney_nature-kit.zip

Archive SHA-256: `fa7974a0d342bfe63c38664ba9f8ec1a4aab8ea25f099bdc56870e33588c4d9d`.
These are shape/size variants, not botanical reconstructions of individual species.
The exporter normalizes height and crown radius, assigns rough nonmetallic autumn
materials, and preserves source topology. Source hashes are recorded in each layer manifest.
