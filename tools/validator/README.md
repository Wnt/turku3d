# tools/validator — Node + Rapier WASM validator for `.col` tiles

Node 24, `@dimforge/rapier3d-compat@0.21.0` (same WASM as the game's `@dimforge/rapier3d@0.21.0`),
`meshoptimizer@1.3.0`. Reads tiles with the shared reader in `game/src/shared/col/` and builds colliders
exactly like the game worker (`buildTileColliders`). Implements ARCHITECTURE Task 1.11.

```
make col-deps                                   # npm ci here (+ pipeline venv)
make col-validate T=fixtures/good FOOTPRINTS=fixtures/good/footprints.geojson OUT=/tmp/report.json
make col-validate T=~/turku3d/data/dist/tiles/collision FOOTPRINTS=footprints.geojson ARGS="--require buildings,curbs,stairs"
make col-validate-fixtures                      # good fixture with the full 2000 walkers (~40 s on the M1 Max)
make col-test-ts                                # tsc + round trip + KCC + fixture tests (node --test)
cd tools/validator && node src/cli.ts --help    # all options
```

Exit code: **0** every check passed (skipped checks do not fail unless named in `--require`), **1** a check failed,
**2** usage/load error. `--out` writes the JSON report (`reportVersion` 1: `tiles[]`, `checks.{format,holes,buildings,curbs,stairs,belowGround}` each with `status` pass/fail/skipped and details, `pass`, `summary`).

## Checks

| Check | What it does | Fails when |
|---|---|---|
| `format` | CRC, version, sizes, shipping rules (material 0 / 200-255, ≤150k tris, ≤1 MB), origin = (i·62.5, 0, j·62.5), bbox ⊇ vertices, FIX flag consistent with FIX_EDGES materials, degenerates, duplicate tile ids | any error |
| `holes` | one jittered downward ray per 0.5 m² (`--ray-density 2`) over the loaded tiles (or `--aoi`) against **solid trimeshes** (primitives and sensors do not count) | any miss |
| `buildings` | `--walkers 2000` KCC walkers start 1–8 m outside a random footprint edge, aim at a random interior point (±30°), 1.5–6 m/s for 10 s. "Inside" = capsule centre > 5 cm inside the footprint **and** a solid above (so standing on a roof is not inside) | any walker inside at any frame or at the end |
| `curbs` | stations every `--curb-spacing 2` m on vertical faces of `curb`, `quay`, `wall` triangles (or along `--curbs` LineStrings). Step = max height 5–45 cm behind the face − height 60 cm in front. Walker starts 1 m on the low side and walks across at each `--curb-speeds 1.5,4` | a step ≤ `--climb-required 0.25` is not climbed, or a step ≥ `--block-required 0.35` is crossed (0.25–0.35 is reported as info) |
| `stairs` | each connected `stair_slope` component: plane fit, slope, rise, run; walker goes up (from 1.2 m below the bottom edge) and down (from 1.2 m beyond the top edge) | either direction does not reach 0.3 m past the far edge at the right height (±10 cm). slope > 40° is flagged |
| `belowGround` | drop walkers every `--drop-spacing 5` m from 1 m above the top surface, plus every 10th frame of **every** walker run above. Below ground = no solid surface at or under the feet, or 2 m below the lowest tile | any sample below ground, or a drop point with no surface |

Walkers never walk off the loaded area (horizontal motion stops 1 m before the edge).

## KCC settings (`src/kcc.ts`)

Capsule r 0.3 / half-height 0.6, offset 0.02, autostep 0.22 / minWidth 0.15, snap 0.3, maxClimb 45°, minSlide 50°.
Two gravity schemes (`--kcc-mode`), measured on Rapier 0.21 (`test/kcc.test.ts` pins these numbers):

| mode | scheme | 1.5 m/s | 4 m/s |
|---|---|---|---|
| `probe` (default) | engine-probe scheme: one move per frame, vy = −0.5 m/s while grounded, full gravity only in the air | climbs ≤ 0.27 m, blocked ≥ 0.30 m | same |
| `split` | horizontal autostep move with y = 0, then a separate vertical gravity move | climbs ≤ 0.22 m, **0.25 m blocks** | climbs ≤ 0.25 m |

At 1.0 m/s neither mode climbs a 0.22 m step (Rapier autostep is speed dependent). The game worker should use
the `probe` scheme (or re-measure) to meet "climbs every curb ≤ 25 cm".

## Inputs

- Tiles: `.col` files or directories (searched recursively).
- `--footprints`: GeoJSON Polygon/MultiPolygon. Coordinates are engine world-local `[x, z]` by default
  (`"turku3d_coords": "engine-xz"`); with `"turku3d_coords": "en"` they are EPSG:3877 `[E, N]` and converted
  with x = E − 23459500, z = −(N − 6704500).
- `--curbs`: GeoJSON LineString/MultiLineString, same coordinate convention.

## Fixtures (`fixtures/`, generated by `make col-fixtures`)

`good/` must pass everything (12 cm and 25 cm curbs climbed, 40 cm step blocked, stair up/down, buildings sealed,
water sensor and query-only treads present); `neg_hole`, `neg_open_building`, `neg_steep_stair`, `neg_material0`
must fail holes+belowGround, buildings, stairs and format respectively. `expected.json` is the contract read by
`test/fixtures.test.ts`.

Codec round-trip fixtures from `make col-test` use `$TURKU3D_WORK/build/col-roundtrip` (override `COL_RT_DIR` explicitly if needed).

## Buildings layer before assembly

`make buildings-validate` checks W1-03 layer NPZ triangles through `src/buildings.ts`;
no shipped `.col` is created. It uses this validator's `Walker`, 2,000 seeded ten-second
trials, and a temporary horizontal pad at each shell's base to isolate wall blocking.
Per-triangle `building_index` provenance indexes `metrics.json.collision_building_ids`.
Each trial enables only the target building's exported triangles. This gives nested parts
valid outside starts and prevents an enclosing building from hiding a broken inner wall.
Missing shells fail coverage and are listed in `missingShells`; existing shells still
receive the complete 2,000-trial run. Any entry into a footprint fails, even if the walker
later exits. This does not replace integrated terrain/vehicle/streaming validation.
Closed/open-wall and nested-part masking regressions are included in `make -j2 buildings-test`.

The gate runs all synthetic assertions with `FIXTURE_WALKERS=32`, two concurrent fixture workers,
and only the explicitly expected checks on each negative fixture. The good fixture still exercises
all checks. Standalone `node --test tools/validator/test/*.test.ts` retains 150 fixture walkers;
set `PIPELINE_PY=$PWD/.venv/bin/python` from the repository root for its codec generator.
`make tile-validate` retains full real-tile sampling and thresholds.

### Parked-car layer probes

`bash pipeline/env/run.sh python -m turku3d.parked.verify` validates the published
`traffic_static` placement audit and generates sandbox report `.col` fixtures.
It invokes `node tools/validator/parked.mjs <collision-directory>` to verify every
solid box using the shared reader/collider builder, player/vehicle interaction
groups, downward rays and capsule/chassis sweeps. Details and build commands:
[`pipeline/turku3d/parked/README.md`](../../pipeline/turku3d/parked/README.md).
