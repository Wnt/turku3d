# Parametric Turku summer crowd

The crowd uses **96 distinct geometry recipes**: twelve clothing/hair families and eight anatomical profiles.
Colour choices add variety but are not counted as models. `src/world/walkers/wardrobe.json` defines the catalogue;
`appearance.ts` assigns a stable identity from each deterministic walker ID. Everyday summer clothes include
T-shirts, shorts, denim, light trousers, skirts, dresses and shirts, with hoodies and light jackets mixed in.
Older profiles have grey hair; native MakeHuman face/age morphs distinguish the family meshes.

All families share the existing CC0 Quaternius UAL skeleton and distance-driven walk/idle clips. The bake
retargets CC0 MakeHuman/CharacterCreator garments and hair, preserves their UVs, and packs their albedos into
one padded atlas. Original unbranded backpacks, cross-body bags and caps are generated by
`scripts/lib/walker-accessories.mjs`, attached to the same skeleton, and merged into the body batch.
No reference photographs or GTA assets enter these files.

## Runtime and budget

- Near: at most 2,800 vertices per family, approximately 3,600–4,400 triangles.
- Far: at most 650 triangles, indexing the same animation texture, with a 22–26 m hysteresis band.
- Twelve instanced family meshes per LOD, one shared material and VAT; model identity does not create another draw.
- Four vertex-buffer bindings with velocity enabled, below WebGPU's guaranteed eight-binding limit.
- One additional instanced soft contact pass. No per-person shadow maps or CPU skeleton updates.
- UV, region and anatomical attributes are static; pose, tint and shape attributes share one instance buffer.
- Body proportions leave the authored feet and forward stride unchanged. Overall height scales stride equally.
- Idle is a breathing stand cycle; walking phase comes from distance travelled. Shoe stance is calibrated against
  the quantized, interpolated animation used on the GPU, rather than only the source keyframes.

`walkers.bin` v2 starts with `TWLK`, u32 version, u32 padded JSON length, JSON, then the sections described there.
The RGBA16F VAT stores model-space xyz and a spherical-Fibonacci normal index. The binary contains the near/far
indices, region IDs and atlas UVs. Exact counts, sources and SHA-256 hashes are in `PROVENANCE.json`.

## Licence and reproducible build

The pinned CharacterCreator generated body, hair, clothing and texture data are **CC0 1.0**, including its
project-original garment extensions. See [MAKEHUMAN-LICENSE-NOTES.md](../character/MAKEHUMAN-LICENSE-NOTES.md).
UAL is also CC0: [QUATERNIUS-LICENSE.txt](../character/QUATERNIUS-LICENSE.txt). The new parametric accessories are
original Turku3D work. No Blender process or paid service is required to rebuild.

From `game/`, fetch the catalogue parts into your own writable cache (never `data/raw`):

```sh
export HUMAN_SOURCE="$TURKU3D_WORK/cache/human-source"
mkdir -p "$HUMAN_SOURCE"
node --input-type=module - <<'JS'
import fs from 'node:fs';
const wardrobe = JSON.parse(fs.readFileSync('src/world/walkers/wardrobe.json'));
const parts = new Set(['base_body', ...wardrobe.families.flatMap(f => f.parts)]);
for (const part of parts) {
  const url = `https://raw.githubusercontent.com/kblood/CharacterCreator/852e48f316b90a0937234886630e4fb4cdfd1f78/output/${part}.glb`;
  const response = await fetch(url);
  if (!response.ok) throw Error(`${part}: ${response.status}`);
  fs.writeFileSync(`${process.env.HUMAN_SOURCE}/${part}.glb`, Buffer.from(await response.arrayBuffer()));
}
JS
git show 2d75e2c56c2db4a011f4197fe16f4367c494e0be:game/public/assets/character/mannequin.glb > "$HUMAN_SOURCE/ual.glb"
node scripts/bake-walkers.mjs "$HUMAN_SOURCE" "$HUMAN_SOURCE/ual.glb" public/assets/walkers
npx vitest run tests/unit/walkers.test.ts
npx tsc --noEmit -p tsconfig.json
```

The atlas packer needs Python with Pillow. The generator uses the project's existing three.js,
meshoptimizer and glTF-Transform dependencies. Identical inputs reproduce the asset byte for byte.
