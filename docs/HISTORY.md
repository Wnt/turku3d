# History

This public repository starts from a single squashed commit, "Import Turku3D source, 2026-10-27", of the cleaned
source tree. The earlier development history (about 400 commits since 2026-10-25) is kept in the author's local
repository and is not published, because older commits contain street-level reference imagery (Google Street View,
Apple Look Around, Mapillary frames, crops and contact sheets) and Google 3D-tile renders that may not be
redistributed. Later commits on `main` are published one per landing, each with the landed tree.
